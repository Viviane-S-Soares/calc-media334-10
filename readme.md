# Calculadora de média

# Objetivos
Treinar javascript, responsividade e criar uma calculadora para me ajudar a calcular minha nota final na escola.
O calculo usado na minha escola é [(n1*3)+(n2*3)+(n3*4)]/10.
sendo: n1 = nota do primeiro trimestre, n2 = nota do segundo trimestre e n3 = nota do terceiro trimestre.
